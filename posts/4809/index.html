Python：利用 WinRAR 开发支持加密和恢复的工具

日常使用 Windows 时，经常需要对文件进行压缩、加密或分卷存储。WinRAR 本身已经提供了比较完善的功能，但如果需要批量处理多个文件和文件夹，操作起来仍然比较繁琐。

因此，我使用 Python 开发了一个简单的批量压缩工具。其并不重新实现压缩算法，而是调用 WinRAR 完成压缩操作。

功能介绍

工具基于 Python 标准库中的 tkinter.ttk 构建，主要支持以下功能：

功能说明
批量压缩支持一次选择多个文件或文件夹
压缩等级提供存储、最快、较快、标准、较好、最好六档
文件加密支持设置 RAR 压缩密码
文件名加密可选择同时加密压缩包内部的文件名
恢复记录支持添加 1%、2%、3%、5%、10% 的恢复记录
分卷压缩支持 100 MB、500 MB、1 GB、2 GB、4 GB、4.7 GB、25 GB
覆盖控制可选择覆盖或跳过已经存在的压缩文件
运行日志在窗口右侧显示 WinRAR 输出
Windows 通知压缩完成后可发送系统通知
深浅色模式自动检测 Windows 应用主题并调整界面颜色
高 DPI 适配支持高分辨率显示器
环境检测启动时自动查找 WinRAR

整个工具没有复杂的安装流程，只需要安装 Python 和 WinRAR 即可运行。Windows 通知功能属于可选功能，不会影响主要的压缩操作。

为什么选择 WinRAR？

Python 本身提供了 zipfile、tarfile 等标准库，可以直接创建 ZIP 或 TAR 压缩文件。

但这次开发有两个比较重要的需求：

  1. 支持压缩包加密，尤其是文件名加密。
  2. 支持恢复记录，提高压缩包在发生局部损坏时的可修复性。

WinRAR 的 RAR 格式能够同时满足这些需求，并且提供命令行接口，便于使用 Python 自动化调用。

压缩格式与数据恢复

压缩与纠错实际上是两个不同的概念。

普通压缩主要通过消除数据冗余减小文件体积，而恢复记录则需要额外保存用于修复损坏数据的信息。

如果压缩包中的一部分数据发生损坏，普通压缩文件可能无法正常解压。尤其是在使用固实压缩时，局部损坏可能影响后续多个文件。

WinRAR 提供了恢复记录功能，可以在创建 RAR 压缩包时额外写入一定比例的恢复数据。

需要注意，恢复记录并不意味着压缩包可以承受任意程度的损坏。

实际修复能力取决于损坏的位置、范围以及压缩包结构。恢复记录比例越高，通常需要付出的额外存储空间也越多。

对于需要长期保存的文件，可以适当提高恢复记录比例，但仍然不能用它替代独立备份。

程序实现原理

整个程序可以分成三个部分：

  1. 使用 tkinter.ttk 创建图形界面。
  2. 根据用户选择生成 WinRAR 命令行参数。
  3. 通过 subprocess 调用 WinRAR，并将输出显示在日志窗口。

总结

这次开发并没有涉及复杂的压缩算法，而是通过 Python 将 WinRAR 已有的命令行功能整合到一个简单的图形界面中。

开发过程中，比较值得记录的技术点包括：

  • 使用 subprocess 调用外部程序。
  • 使用 threading 避免 Tkinter 界面卡死。
  • 使用 root.after() 实现线程安全的界面更新。
  • 使用 winreg 检测 Windows 应用主题。
  • 使用 ctypes 调用 Windows API。
  • 使用 tk.Entry 解决 ttk 输入框深色模式适配问题。
  • 使用 WinRAR 的命令行参数实现加密、恢复记录和分卷压缩。
